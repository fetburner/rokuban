# ファビコンと走査線

ファビコンは白黒テレビに映る「イ」を、走査線の縞で描いた図像にする。走査線は 3 値で描き、SVG はスクリプトで生成する。

## ファビコンは白黒テレビに映る「イ」

ファビコンは、白黒テレビに映った「イ」の図像にする。1926 年に高柳健次郎がブラウン管へ映した日本初のテレビ映像が「イ」で、放送そのものの起点を指す。書体は Noto Sans JP Black で、明朝は使えない。プロダクト名とは関係しないが、放送の起点を指す図像として使う。

「イ」はいろは順の最初の文字で、ABC の A に相当する。画の配置は[元画像](https://dndi.jp/20-tani/images/09110901.jpg)に寄せる。

- 白地に黒にする。被写体は雲母板に墨で書いた文字なので、画面が明るく字が暗い
- 枠は黒い四角だけにする。ダイヤルやスピーカーグリルは入れない
- 走査線を縞として描く。元画像は輝線の間隔が広く、縞に見える

### 書体

字形は Noto Sans JP Black にする。元画像の毛筆の字体を再現しようとしたが、筆の形を自作すると、細部（入筆の押さえ、二画目の運筆）が原典から外れる。既存の書体を使う方が確実である。

**明朝は使えない。**「イ」の二画目は止めだが、明朝は縦画が下へ向かって細り、末端が尖る。ゴシックは縦画が等幅で、末端が平らに止まる。Black を選んだのは 16px での可読性のためで、Bold では縦画が灰色に沈む。

## 走査線は 3 値で描く（白黒 2 値だと字が消える）

輝線 = 白、間隙 = 灰、字 = 黒の 3 値で描く。輝線と間隙を白黒 1:1 にして黒い字を乗せると、字が間隙と融合して読めなくなるためである。元画像がそう見えないのは、字の上を走査線が暗く通っていて、字自体が中間の灰になっているからである。

そこで灰の割り当て先を入れ替える。3 値にすると、字がどの階調とも衝突せずに読める。元画像（輝線 = 白、間隙 = 暗、字 = 灰）の階調構成を保ったまま、小さいサイズで機能する方に灰を移した形である。

走査領域の境界は偶数座標に取り、周期 2（輝線 1 + 間隙 1）にする。32px 描画では輝線が 1px で、画素境界に乗る。16px では 0.5px になって縞は溶けるが、明るい画面として残るので字は読める。

## ファビコンはスクリプトで生成する

ファビコンの SVG はスクリプトで生成し、文字要素を使わずパスで持つ。レンダリング環境のフォントに依存すると、字形と太さがプラットフォームで揃わないためである。ヒラギノは Apple のプラットフォームにしか無い。生成物は直接編集しない。

### 生成と書体の権利

輪郭を同梱するので、書体は再配布が許諾されているものから選ぶ。Noto Sans JP は SIL OFL 1.1 で使え、ヒラギノは輪郭を同梱する権利がないので使えない。

スクリプトが、枠・走査線・字形の配置を組んで SVG を吐く。字形は、フォントをラスタライズして potrace でトレースした輪郭を定数で持っており、再生成の手順はスクリプト先頭のコメントにある。Noto Sans JP の著作権表示（Copyright 2014-2021 Adobe）は、生成される SVG のコメントに入れている。

<details><summary>根拠</summary>

- 生成スクリプト: `web/scripts/gen-favicon.mjs`
- 生成物（直接編集しない）: `public/favicon.svg`（ファイル名 `favicon.svg`）
- 文字要素を使わない: `<text>`

</details>

### ライセンス表示

自前配布する Web フォント（Geist Variable / Noto Sans JP Variable）を含む、依存全体のライセンス表示は、静的ファイル置き場の生ファイルに置く。CSS のバナーコメントは Tailwind のビルドで落ちるためである。

生ファイルならビルドを経由せず、生成物に各フォントパッケージの LICENSE 全文が入る。成果物だけを取り出しても、OFL 1.1 の表示が完結する。

<details><summary>根拠</summary>

- ライセンス表示の置き場: `public/THIRD_PARTY_NOTICES`
- 落ちるバナーコメント: `/*! ... */`
- 成果物: `dist/`

</details>

### ラスタ版とフォールバック

ラスタ版は外部ツール（rsvg-convert / ImageMagick）で作り、自動化していない。SVG に対応しない古い Safari 向けに ICO を併記し、iOS 向けに apple-touch-icon も置く。

ラスタ版は npm 依存にない外部ツールで作るため、自動化していない。SVG のアイコンは Safari 16 未満で無視されるので、ICO を `alternate icon` として併記する。PWA は入れないが、iOS の「ホーム画面に追加」はマニフェストなしでも使われ、指定がないと画面のスクリーンショットが使われてしまうため、apple-touch-icon を置く。

静的ファイル置き場に置いたファイルは Vite が成果物の直下に出すので、go:embed 経路と S3 経路の両方に自動で乗る。

<details><summary>根拠</summary>

- ラスタ版: `favicon.ico`、`apple-touch-icon.png`
- SVG の指定: `rel="icon"`
- 静的ファイル置き場: `public/`
- 成果物: `dist/`

</details>
