### SPA アセット配信

SPA アセットは、バイナリに埋め込んだまま配る。ハッシュ付きのアセットは immutable、それ以外は no-cache になるヘッダーを正しく付ければ十分である。

実装は `go:embed` 配信である（参照: [frontend.md](../../frontend.md)）。本気の配信最適化は S3+CDN 経路の仕事で、ここに nginx キャッシュを挟むと配信経路が 3 つになり、テストマトリクスが増える割に得るものがない。

### サービスロゴ: ドロップ

サービスロゴは Rokuban 側で再取得も自前配信もせず、実装しない。そうする価値が薄いためである。

mirakc は起動中の局ロゴ抽出をサポートせず、運用者が事前抽出したファイルを静的登録して配るだけの機構しか持たない（[data.md](../../data.md) の「サービスロゴ: ドロップ」参照）。
